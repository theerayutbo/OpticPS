# Changelog

## Unreleased (v1.2 UXR)
Scope export import (HDF5, CSV, and BIN behind an explicit unverified flag), a linear non-periodic capture analysis with preamble-based frame finding and symbol-clock estimation, `opticps ingest-uxr`, and the Southampton UXR protocol. Tested on synthetic files only; no real UXR export has been seen. Transmitter waveforms are unchanged.

## 1.0.0 (2026-10-30)
First release. M8199B waveform packages for two profiles, exact CCDM, IM/DD link simulation, receiver DSP, capture ingest, fair comparison tools, simulated demonstration, report and slides. No measured data. M8199B playback not verified.
