# Dependency exceptions and audit notes

Human-readable log for Gate 0 (roadmap v2 section B.6). Machine-readable inventory: `docs/sbom.cdx.json`. Method: `uv run python scripts/license_audit.py`, run 2026-10-31 on branch `v1.3-mpam` at `a2eb969`. It reads the licence field of every installed distribution and fails on GPL, LGPL, AGPL or UNKNOWN.
