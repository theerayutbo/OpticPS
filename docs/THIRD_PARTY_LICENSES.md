# Third-party licences

Runtime dependencies are installed, not vendored. Versions are pinned in `uv.lock`. The full list is in `docs/sbom.cdx.json`, generated by `scripts/license_audit.py`.

| Package | Licence (from installed metadata) |
|---|---|
| numpy | BSD-3-Clause AND 0BSD AND MIT AND Zlib AND CC0-1.0 |
| scipy | BSD |
| matplotlib | Matplotlib licence (PSF-style) |
| PyYAML | MIT |
| python-pptx | MIT |
| reportlab | BSD |
| h5py | BSD-3-Clause |
| lxml | BSD-3-Clause |
| pillow | MIT-CMU |
| xlsxwriter | BSD-2-Clause |
| typing_extensions | PSF-2.0 |

DejaVu Sans is taken at build time from matplotlib's bundled fonts. It is embedded in generated PDFs under the Bitstream Vera/DejaVu licence, which permits embedding.

No proprietary Keysight code or binaries are included.
