# Attribution: TERIPHIC photodiode-array dataset

The files in this directory (`b2b_model.yaml`, `scenario_list.yaml`, `power_study.yaml`,
`preregistered_predictions.yaml`) hold statistics and model outputs derived from a back-to-back capture of the
following dataset.

- Title: Experimental characterization of TERIPHIC 4-fold and 8-fold InP photodiode arrays - Detection of 50Gbaud
  signals with NRZ and PAM-4 modulation formats
- Creators: Panos Groumas, Efstathios Andrianopoulos, Christos Tsokos (ICCS). Contributors: David De Felipe,
  Norbert Keil, Patrick Runge (Fraunhofer HHI); Paraskevas Bakopoulos (NVIDIA)
- Record: Zenodo record 7886498, https://zenodo.org/records/7886498 (concept DOI 10.5281/zenodo.7886497)
- DOI: 10.5281/zenodo.7886498
- Published 2023-05-02 on Zenodo
- Funding named by the record: EC H2020 TERIPHIC, GA 825502
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/

Changes: the derived statistics and model outputs in this directory were computed by OpticPS from the
back-to-back capture only. The raw data are not redistributed in this repository. Values are summaries and
model results, not samples of the capture.

Source details and the record's read status are in `docs/benchmarks/SOURCE_REGISTER.md` (Source 1).
