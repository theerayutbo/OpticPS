# Clean-room declaration

This is a description of the development process, not a legal certification.

- OpticPS was written from published equations and general communication theory.
- The four background repositories (OptiCommPy, Probabilistic_Constellation_Shaping, PAM4Receiver, OpticalSimulation) were not cloned or opened. Only their licence metadata was read through the GitHub API.
- OptiCommPy (GPL-3.0) is not a dependency.
- Development was AI-assisted (Claude Code; a separate Fable model pass reviewed the design).

Independent implementation, licence scanning, provenance review and human legal review are distinct safeguards. Only the first three have been done here. **Human legal review has not been done**, and neither has a review against University of Manchester IP policy; that remains with the copyright holder.
